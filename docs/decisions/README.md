# 决策记录（ADR）

放"为什么当初这么选"的记录。代码回答"是什么"，这里回答"为什么"——半年后最常被问的正是后者。

## 已有记录

- [0001 规则优先的提问诊断，LLM 只做可选润色](0001-rule-first-question-diagnosis.md)

## 何时写

- 选了一个以后不好换的东西（数据库、框架、协议、目录分层）；
- 否掉了一个看起来更明显的方案；
- 定了一条会影响很多人的约定。

## 文件命名

`0001-use-postgres.md`、`0002-single-entry-point.md`：四位序号 + 短横线 + 一句话。

## 模板

```markdown
# 0001 标题

- 状态：提议 / 已采纳 / 已废弃
- 日期：YYYY-MM-DD

## 背景
当时面对什么问题，有哪些约束。

## 决定
我们选了什么。

## 后果
付出了什么代价，换来了什么；什么情况下要重新考虑。
```
