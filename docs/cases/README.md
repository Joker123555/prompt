# 对话案例

记录真实对话的复盘：当时怎么问、对方怎么回、事后看哪里偏了、下一次怎么改。

## 格式

每个案例一个文件：`0001-short-title.md`，包含：

- **背景**：关系与场景、当时的目标；
- **原话**：实际说出的那句话（可脱敏）；
- **结果**：对方或 AI 怎么回，哪里没达到预期；
- **复盘**：用哪些槽位看，缺了什么；
- **下一次**：改写后的说法；
- **可迁移的点**：一条就够。

案例不是范文，是证据。宁可保留当时的粗糙原话，也不要把事后总结伪装成当时的想法。
